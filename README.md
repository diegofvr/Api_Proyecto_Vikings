# Vikings API

API REST desarrollada con **Spring Boot** para la gestión de productos.

##  Características

- Listado de productos
- Consulta de producto por ID
- Arquitectura basada en capas (Controller - Repository)
- Spring Data JPA
- Base de datos en memoria (H2) para desarrollo

##  Tecnologías

- Java 17+
- Spring Boot
- Spring Data JPA
- Maven
- H2 Database (desarrollo)
